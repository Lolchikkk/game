# Closetape ClipMaker

Веб-интерфейс для подготовки горизонтальных MP4-фрагментов из Twitch VOD.

## Что уже есть
- Адаптивный интерфейс для Safari/iPhone.
- Backend на FastAPI: скачивание доступного VOD через yt-dlp, анализ аудио, опциональная транскрипция Faster-Whisper, экспорт MP4 и ZIP.
- Проверка формата Twitch VOD URL.
- Экспорт с исходной геометрией кадра, звуком, без субтитров и эффектов.

## Важно: две части приложения
GitHub Pages размещает только статический интерфейс. GitHub не запускает FFmpeg или Python. Для обработки нужен отдельный сервер с FFmpeg, достаточным диском и CPU.

## Локальный запуск backend
Требуется Python 3.11+ и FFmpeg:
```bash
pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
В `index.html` перед основным скриптом добавь адрес backend:
```html
<script>window.CLOSETAPE_API = "https://YOUR-BACKEND-DOMAIN";</script>
```

## Docker
```bash
docker build -t closetape .
docker run --rm -p 8000:8000 -v closetape-data:/data closetape
```
Проверка backend: `/api/health`.

Для транскрипции задай переменную окружения `FASTER_WHISPER_MODEL` (например, `small` или `medium`). Модель скачивается при первом запуске. Если транскрипция выключена или недоступна, используется запасной отбор по пикам громкости — это не семантический AI-анализ.

## Ограничения MVP
- VOD должен быть доступен yt-dlp. Приватные, удалённые и ограниченные записи могут не скачаться. Не вводи пароль Twitch; авторизация/cookies не запрашиваются.
- Хранилище задач пока в памяти процесса; перезапуск сбрасывает статусы. Для публичного сервиса нужны очередь задач, БД, очистка временных файлов, лимиты, авторизация, rate limiting и мониторинг.
- Видео занимают много места. Настрой persistent disk и очистку.
- Для точной нарезки видео перекодируется в H.264/AAC (CRF 18): качество высокое, но это не lossless.
- Используй только записи, которые вправе скачивать и редактировать.

## GitHub Pages
Включи Settings → Pages → Deploy from a branch → main → /(root). Интерфейс будет опубликован, но обработка заработает только после настройки `window.CLOSETAPE_API` на развёрнутый backend.
